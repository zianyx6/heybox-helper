# 黑盒助手 0.11.0

> 非官方社区扩展，与小黑盒及其运营方没有隶属或授权关系。仅用于调整浏览器中的网页显示；不绕过登录、扫码或付费限制。

面向小黑盒网页的主题与社区扩展，支持 Edge / Chrome。完整源码随测试包提供。

## 安装与更新

1. 解压到固定目录，保留包含 manifest.json 的 heybox-helper 文件夹。
2. 打开 edge://extensions 或 chrome://extensions，开启开发人员模式，点击“加载解压缩的扩展”，选择该文件夹。
3. 更新已有安装：将新文件覆盖到原扩展文件夹，在扩展管理页点击刷新。
4. 关闭旧的小黑盒标签页，再打开 https://www.xiaoheihe.cn/app/bbs/home 。

## 在网页里设置

点击网页右下角“设置”，打开页面内设置面板。浏览器工具栏的扩展按钮也能定位并打开网页设置。设置自动保存。

- 个性化外观：晴空蓝、樱花粉、薄荷绿、鸢尾紫、暖砂色五套预设；选择“自定义”可设置主色和页面底色。原生内容卡片保持不透明白底，确保文字可读。
- 圆角与间距：三档圆角，舒适 / 紧凑间距。关闭个性化外观可撤销主题样式。
- 本地图片背景：导入 JPG / PNG / WebP，最大 8 MB、2400 万像素；自动缩小与压缩，只保存在浏览器扩展存储，不上传。可调整可见度、移除图片。删除源文件后背景仍保留；卸载扩展会删除扩展存储。
- 社区布局：社区工作区、简洁导航。沿用已有设置，新安装默认关闭这两项。
- 本机隐藏的帖子：恢复通过“不感兴趣”隐藏的内容。
- 阅读：字号、行距、内容最大宽度、回到顶部。
- 登录诊断：查看记录概况、导出报告、清空记录。报告不含 Cookie 值、背景图片或本机隐藏列表。

内容宽度受浏览器空间限制，工作区会为左侧社区保留位置。按 Esc 或点面板外可关闭设置。

## 社区工作区

左侧有社区动态、关注动态和快捷社区。在社区、用户主页或创作者内容管理页点击关注动态，会先切到社区首页，再加载关注用户的近期帖子。支持 Ctrl 点击和新标签页打开。

搜索框输入时筛选快捷项，按回车搜索官方社区目录。主页与社区页面点击可识别的帖子链接，在站内弹窗查看正文与评论。

## 不感兴趣

在帖子右上角点击三个点，选择“不感兴趣”。这只会在本机隐藏当前帖子，不向小黑盒提交推荐反馈，不影响原站推荐算法，也不等于屏蔽作者。

隐藏结果保存在当前浏览器扩展存储，刷新后仍有效，最多保留 1000 个帖子 ID。可在提示条点击“撤销”，或在设置内“本机隐藏的帖子”点击“全部恢复”。菜单中的“原站更多操作”保留原站菜单入口。无法可靠识别帖子的内容不会被自动隐藏。

## 已知限制

- 关注动态按批次读取各用户近期帖子，并非官方完整关注时间线。
- 官方社区目录可能不包含全部社区。
- 登录诊断不等于会话续期；尚未实现自动续期。
- 依赖网站现有接口和组件，原站更新可能需要适配。
- 这是手动加载的测试版，不会自动升级。

## 应用商店发布前

关注动态功能会在运行时调用小黑盒网站提供的前端模块，以读取官方网页数据并渲染原生帖子卡片。Chrome Web Store 与 Edge Add-ons 对 Manifest V3 扩展执行远程 JavaScript 有限制；因此 0.11.0 可供源码审阅和开发者模式测试，但提交商店前需要把该功能改为不执行远程代码的实现，并按商店要求填写权限、数据收集和隐私政策说明。

0.10.0 实际加载扩展验证了樱花粉、背景导入/移除、原关闭状态自动启用、刷新保存、分类设置、动态效果开关、系统减少动态效果、首页与消息卡片一致性、游戏按钮与窄屏边界、闲置无循环动画或 DOM 修改。另在实际未登录小黑盒页面确认了主题/背景应用与刷新保留，实际 CS2 游戏详情可渲染；没有触发真实购买或发布操作。

0.9.0 的 Edge 检查覆盖真实扩展加载、消息入口与布局、自己的帖子入口、评论输入区与发送回调保持、头像身份校验、滚动条避让、关注流增量更新 / 并发上限 / 缓存与账号切换 / 取消 / 重试，以及空闲时无持续修改。帖子发送与关注接口使用模拟数据；没有代用户发布真实评论。实际未登录消息中心可打开；公开帖子正文在无扩展的未登录基线中也未加载，不能据此确认真实登录后的评论兼容性。

0.8.0 在独立 Edge 155 中实际加载了解压扩展，验证设置保存与同步、主题预设与自定义主色、图片导入移除、诊断导出脱敏、本机隐藏与撤销、设置恢复隐藏内容、空闲时无持续 DOM 修改。在未登录的小黑盒实际公开页面验证了主题面板与真实帖子的隐藏/撤销。

跨页关注流、路由取消、图片尺寸及存储失败、动态卡片、旧版布局等另以模拟页面回归。未使用个人登录资料，不能代替真实账号下的完整关注流测试。
